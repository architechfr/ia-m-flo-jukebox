IA-M.Flo — Jukebox

Site statique reprenant le jukebox 3D original.
Catalogue : Special Version, Radio Edit, album Tout ce qu’on ne dit pas (9 titres).
La musique est lue par le lecteur YouTube officiel et nécessite Internet.

Déploiement Vercel : Framework Preset = Other ; aucun build ; dossier racine = ce dossier.
Pour le prévisualiser localement : python -m http.server 8000, puis ouvrir http://localhost:8000.
Les fichiers doivent être servis par HTTP, pas ouverts directement par double-clic.

Vérifications : syntaxe JavaScript, catalogue et liens contrôlés.
Lecture YouTube et rendu 3D sur téléphone restent à tester après déploiement.
